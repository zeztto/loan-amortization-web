# 대출 상환 계산기

대출 금액·고정 연이율·기간·거치 기간으로 네 가지 상환 방식의 월별 표를 계산합니다. 계산한 snapshot을 실제 `.xlsx`와 한글 텍스트 PDF로 내려받을 수 있습니다.

## 실행

Node.js 22 이상과 npm이 필요합니다. API key·계정·환경 파일·외부 금융 API가 필요하지 않습니다.

```sh
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1
```

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/`는 도메인 root의 HTTPS 정적 hosting에 배포할 수 있습니다. build 시 LICENSE·runtime notice·font OFL 원문도 함께 복사합니다. Vite dev/preview는 로컬 확인용입니다. lockfile과 CI action commit SHA를 고정했습니다. CI는 Node 22·Ubuntu에서 clean install·검사·build·audit를 실행하도록 구성했으며 원격 CI와 공개 배포 실행은 별도입니다.

## 계산 정책

- 원리금균등: 거치 후 같은 명목 월 상환금을 적용하며 마지막 회차의 잔여 원금을 조정합니다.
- 원금균등: 거치 후 원금을 정수 원 단위로 나누고 마지막 회차의 잔여 원금을 조정합니다.
- 만기일시: 매월 이자를 납부하며 마지막 회차에 원금을 상환합니다. 거치를 지정해도 이 구조는 같습니다.
- 체증식: 거치 후 첫 회차를 이자액으로 시작하고 이후 납부액을 매월 일정액 늘리는 모형입니다. 증가액은 거치 후 상환 기간의 할인 현금흐름으로 구합니다. 상환 기간이 1개월이면 원금과 이자를 한 번에 납부합니다. 특정 금융기관의 체증식 상품 규칙을 재현하지 않습니다.

연 이율을 12로 나눈 월 이율을 사용합니다. Decimal.js의 50자리 정밀도로 명목 상환금을 구하고 매월 이자·상환금을 원 단위로 사사오입합니다. 월 이율이 `1e-30` 미만인 극소 금리는 지원 금액·기간에서 정수 원 결과가 같도록 0%의 극한값을 사용해 분모 취소오차를 피합니다. 매월 원금은 잔액을 넘지 않으며 마지막 회차 원금으로 잔액을 0원으로 맞춥니다. 반올림과 작은 원금·긴 기간의 조합에서는 마지막 상환금이 다른 회차보다 커질 수 있습니다. 요약 합계는 실제 표의 정수 원 금액을 더한 값입니다.

대출 금액은 1원~1조 원의 정수, 연 이율은 0~100%, 기간은 1~600개월, 거치는 0~기간 미만의 정수 개월입니다. 만원·억원 버튼은 단순 승수이며 변환한 원 금액이 정수여야 합니다. 이율은 입력한 Decimal 값과 Number의 십진 표현을 비교해 정밀도 손실이 생기는 긴 소수를 입력 오류로 거부합니다. 일반 금리와 유효한 극소 금리는 일반 십진 소수 입력으로 계속 지원합니다. 빈 거치 입력은 0개월입니다. 1년=12개월·30일=1개월로 환산하며, 0.5년·60일처럼 정수 개월로 변환되는 입력만 지원합니다. 31일·1.5개월은 계산하지 않습니다.

실제 상품의 날짜별 이자·윤년·납입일·세금·수수료·변동 금리·중도상환 규칙은 포함하지 않습니다. 결과는 위 가정의 상환 모형이며 금융기관의 견적이나 계약 금액을 보장하지 않습니다.

## 입력과 파일

입력·단위·상환 방식을 바꾸면 이전 결과·표·내보내기 버튼을 즉시 비웁니다. 계산 당시 입력 snapshot으로 요약·표·파일을 만듭니다. 잘못된 계산과 초기화 뒤에 이전 결과를 남기지 않습니다. 저장소·계정·자동 저장·PWA 설치 기능은 없습니다.

- XLSX: `요약`과 `상환일정표` 두 sheet, 실제 금액 숫자 셀, 원화 서식과 고정 header를 사용합니다. 이자율은 극소 양수를 0%로 표시하지 않도록 계산에 사용한 값과 `%`를 text로 보존합니다. CSV 또는 이름만 바꾼 `.xls` 파일이 아닙니다.
- PDF: NanumGothic Regular/Bold를 포함한 A4 문서입니다. 한글 텍스트를 선택할 수 있으며 여러 페이지에 표 header를 반복합니다. 글꼴은 PDF 내보내기를 누를 때 로드합니다.
- 파일명은 상환 방식과 계산 시점의 시간을 포함합니다. 다운로드 요청 안내는 운영체제의 실제 저장 완료를 뜻하지 않습니다. 실행 환경의 다운로드 차단 여부는 브라우저 설정에 따릅니다.

## 검증 범위

독립 반복 현금흐름·이분법과 BigInt 이자 반올림 참조로 네 방식·거치·0%·최대 기간·최종 원금 보존을 검사합니다. 실제 hook의 입력 변경·잘못된 계산·초기화, XLSX ZIP/OpenXML 숫자 셀·서식, PDF header·Unicode font·page tree 회귀를 포함합니다.

별도 openpyxl/pypdf decoder로 12회차와 600회차 산출물을 열어 마지막 잔액·숫자 셀·한글 텍스트를 확인하고, 2페이지·18페이지 PDF를 렌더링해 표 배치를 확인했습니다. openpyxl은 기본 workbook style이 없다는 경고 후 자체 기본 style을 적용했으며 원화 숫자 서식과 값은 유지됐습니다. 실제 Microsoft Excel·LibreOffice·모든 PDF viewer에서의 호환성을 확인한 것은 아닙니다. 브라우저의 실제 흐름·다운로드·반응형 검증 결과는 별도 QA 증거로 관리합니다.
